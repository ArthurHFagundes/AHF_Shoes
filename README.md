# 📌 AHF Shores - Fictional E-commerce

Responsive website for a fictional shoe store e-commerce, developed for study purposes.

🌐 Access the project:
[Project Website](https://ahf-shoes-2-0.vercel.app/)

## 📖 About the Project

This website was built using only pure HTML and CSS, as I was beginning my studies in Web Development.

## ✨ Features

* Navbar / Header with navigation links to sections within the page.
* Hero section with auto transitioning banners.
* Featured products section showcasing the best-selling items, including purchase button animations.
* Promotions section with integrated category tabs.
* Contact section with name, mail, phone, and message input fields, along with a submit button.

## 🛠️ Technologies Used

- Front-End:
    - HTML5
    - CSS3
- Tools:
    - GitHub
    - Vercel

## 🎯 Purpose

This project was created to:

* Demonstrate my technical skills;
* Practice and improve my knowledge of HTML and CSS features.

## 📄 License

This project was developed for educational and professional portfolio purposes.
